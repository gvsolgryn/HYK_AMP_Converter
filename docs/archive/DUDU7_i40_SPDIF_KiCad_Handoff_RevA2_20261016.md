# DUDU7 → Hyundai i40 순정 AMP S/PDIF 변환기

> **KiCad / 로컬 AI 에이전트 설계 인수인계 — Rev.A2**  
> 갱신: **2026-10-16**  
> 상태: **역설계한 OEM 출력단의 수정 회로 반영 / 신규 SCH 설계 준비 / 부품 미구매 / PCB 미제작**  
> **제작 승인 문서가 아니다.** 제조사 데이터시트, SCH/ERC, PCB/DRC, 회로 전기적 검증과 차량 시험이 끝나기 전 Gerber를 발주하지 말 것.

## 0. 가장 중요한 최신 수정 사항 (과거 자료보다 우선)

1. **2026-10-16 사용자 제공 최종 KiCad 화면**을 순정 AVN S/PDIF 출력단 역설계 기준으로 삼는다. 최초에 그린 KiCad 사진과 이 문서보다 오래된 SVG/MD보다 **최신 그림이 우선**이다.
2. **U400 MAX3295의 정상적인 Y/Z 극성으로 수정됨:** `Y (6번) → R420 (120Ω) → F400 → SPDIF+`; `Z (4번) → R419 (120Ω) → F400 → SPDIF−`.
3. **U400 `DE(3번)`와 `VCC(2번)`가 실제 순정 PCB에서 연결된 패턴을 사용자 확인함.** 정상 전원이 공급되는 동안 드라이버를 활성화하는 구성으로 해석한다. 단, 최종 KiCad 복원도에서는 VCC/DE가 서로 연결된 것만 표현되어 있고 전원 레일 및 디커플링은 별도로 완성해야 한다.
4. OEM `R419=119.9Ω`, `R420=120.2Ω`, `R423=56.4Ω`, `F400`의 두 권선 경로 `0.9Ω/1.0Ω`를 **Fluke 101로 실측함**. R423 양단이 `SPDIF+`와 `SPDIF−`에 연결됨을 확인.
5. **순정 출력의 네 EMI 커패시터 `C593`, `C433`, `C430`, `C431`는 실제 용량 미확정.** Fluke 101으로 회로 내 측정한 nF 값은 부품 정격으로 복제하면 안 된다. Rev.A는 네 풋프린트를 모두 넣고 **초기 DNP**로 시험한다. `U1/U2/U3/U4` 전원용 디커플링은 DNP 대상이 아니다.
6. 신규 PCB는 **기본적으로 순정과 같은 `Y→SPDIF+ / Z→SPDIF−` 극성**을 따른다. **선택형 극성 교환용 0Ω 저항 4개 풋프린트(2개만 실장)**를 옵션으로 설계한다. 두 조합을 동시에 실장하면 안 된다.
7. 전원부 권장안은 **`ACC 12V → 퓨즈·역극성·서지 보호 → 5V Buck → 3.3V LDO`**이다. 구버전 `12V→3.3V LDO 단독` 및 `상시 B+→ACC EN 제어` 회로와 BOM은 더 이상 기준이 아니다.
8. **기성 소형 알루미늄 케이스** 기준, **2-layer PCB / 전 부품 Top 실장 / Bottom GND plane**, BNC 입력은 케이스 패널에 고정한다.

## 1. 프로젝트 목표와 경계

- 차량: **Hyundai i40**.
- 순정 AMP 후보/기존 사용자 제공 품번: **`96370-3Z101`**.
- 입력: **DUDU7 Android Head Unit의 RCA Coaxial S/PDIF OUT**.
- 출력: 차량 OEM AMP의 **`SPDIF+`, `SPDIF−`, `SPDIF GND`**.
- 기능: 입력의 **IEC60958/S/PDIF Biphase-Mark Code(BMC) 신호를 복호화하지 않고**, 동축 신호를 로직 전압으로 정형하여 **차동 전기신호**로 전달한다.
- 새로운 S/PDIF 인코더/디코더, 별도의 MCU, DAC를 추가하는 프로젝트는 **아님**.
- 최우선 목표: **순정 AMP 동작 / 시동 OFF의 불필요한 배터리 전력소모 방지(IBS) / 안정된 EMI·파형 / 소형 케이스 장착**.

```text

      │
      │ RCA Male ───── 유연한 75Ω 동축 케이블 3~5m (5m 선호) ───── BNC Male
      ▼
[알루미늄 케이스 패널의 75Ω BNC Female]
      │ 짧은 75Ω 피그테일 (또는 규격 맞는 PCB 연결)
      ▼
[75Ω 종단 / AC coupling / 입력 바이어스]
      ▼

      ▼
[OEM 복원값 기반 저항 / F400 대체 CMC / 선택형 EMI 필터]
      ▼
[J3: SPDIF+ / SPDIF− / SPDIF GND]
      ▼
[Hyundai i40 OEM AMP]
```

> 위 연결은 설계 의도다. **DUDU7의 실제 RCA 전압 및 순정 AMP의 수신 전기적 규격은 아직 측정되지 않았다.**

## 2. 근거의 등급 — 무엇이 확정이고 무엇이 가정인가

### 2.1 순정 AVN 출력단: 사용자 실제 PCB 관찰 및 Fluke 실측

| 부품/경로 | 관찰·측정 | 현재 상태 |
|---|---|---|
| U400 | 순정 AVN에 MAX3295 사용 | 확인 |
| U400 `Y(6)` → R420 → F400 → `SPDIF+` | 사용자 최종 KiCad 수정 회로 | **최신 기준 회로에 반영** |
| U400 `Z(4)` → R419 → F400 → `SPDIF−` | 사용자 최종 KiCad 수정 회로 | **최신 기준 회로에 반영** |
| U400 `DE(3)` ↔ `VCC(2)` | PCB 패턴 연결 발견 | **확인** |
| R419 | `121` 마킹, 실측 **119.9Ω** | **120Ω 공칭값 확정** |
| R420 | `121` 마킹, 실측 **120.2Ω** | **120Ω 공칭값 확정** |
| R423 | 실측 **56.4Ω**, 두 단자는 각각 SPDIF+/− 출력 Net에 연결 | **56Ω 차동 병렬저항** |
| F400 | 4단자, 각 경로 DC 측정 **0.9Ω / 1.0Ω** | **2라인 CMC 추정**. 정확한 부품과 고주파 임피던스는 미확정 |
| C593 | U400 Y/Z 쪽, R419/R420 **앞**의 차동선 사이 | **연결 위치는 최종 복원 SCH 기준**, 값 미확정 |
| C433 | F400의 커넥터 쪽, SPDIF+/− 사이 | **값 미확정** |
| C431 | `SPDIF−` → GND | **값 미확정** |
| C430 | `SPDIF+` → GND | **값 미확정** |

**중요:** 사용자가 제공한 최종 KiCad 화면은 순정 AVN의 PCB 패턴을 보면서 작성한 복원 회로다. **그림을 사용자 기준으로 신뢰하되 실제 제조사의 원본 회로도가 존재한다는 뜻은 아님**. 오래된 최초 복원본의 `Y→SPDIF−`, `Z→SPDIF+` 표기는 **폐기**한다.

### 2.2 순정 회로의 개념적인 배선

```text
                         순정 AVN U400 (MAX3295)
                       ┌────────────────────────┐
SPDIF 데이터 (미추적) → │ DI(1)                  │
+VCC 순정 전원       → │ VCC(2) ─── DE(3)      │   [두 핀 연결 확인]
GND                  → │ GND(5)                 │
                       │                        │
                       │ Y(6) ────────────┬─────┼── R420 120Ω ──┬─ F400 선로 B ── SPDIF+
                       │                  │     │              │
                       │ Z(4) ────────────┼─────┼── R419 120Ω ──┼─ F400 선로 A ── SPDIF−
                       └──────────────────┼─────┘              │
                                          └── C593 ────────────┘  ← C593은 저항 전단 Y/Z 사이

  F400 이후 외부 커넥터 쪽: R423 56Ω 및 C433는 SPDIF+ ↔ SPDIF− 사이,
  C430은 SPDIF+ ↔ GND, C431은 SPDIF− ↔ GND.
```

> ASCII 도식의 선 교차는 시각적 개념이며 **전기적 단락을 뜻하지 않는다**. 실제 복원된 KiCad 최신 SCH 화면에서 Net을 결정한다. 각 위치의 정확한 배치 순서(저항 ↔ CMC ↔ 커패시터)는 사용자의 최신 SCH를 우선한다.

### 2.3 커패시터 측정 데이터 — **복제 금지**

- Fluke 101, PCB 실장 상태 측정: `C430 ≈0.6nF`, `C431 ≈0.6nF`, `C433 ≈0.07nF`.
- 실제 정전용량이라고 볼 수 없다. 내부 병렬 경로, 케이블·프로브 기생 정전용량, Fluke 101의 저용량 측정 성능 때문.
- **탈거를 강요하지 않는다.** 정밀 LCR 미터 확보 전까지 `TBD`, 신형 Rev.A 보드에서는 4개 EMI용 커패시터를 초기 **DNP**로 둔다.
- C430/C431가 서로 같은 정전용량일 수는 있지만 아직 측정으로 확인하지 못했다.

### 2.4 순정 S/PDIF 발생원 역추적 — 현재 보류

- 순정 PCB 사진에서 `Cirrus Logic CS8406` S/PDIF 송신 IC와 `NXP SAF7741HV` 오디오 DSP로 추정되는 IC를 찾음.
- **CS8406 `TXP(26)` ↔ U400 `DI(1)` 및 `TXN(25)` ↔ U400 `DI(1)`은 사용자 Fluke 측정 시 모두 `OL`.** 따라서 직접적인 DC 도통 경로는 확인되지 않았음.
- `U400 DI(1)`에서 이웃 VIA, U103 근처 홀, 반대면 CN102 근처 홀 쪽으로 통전되는 지점을 찾았으나 **정확한 신호 공급원은 특정하지 못함**. PCB 내부층일 가능성.
- **현재 역추적은 중단**하고 신규 테스트 PCB 설계를 우선한다. CS8406이 U400의 직접 신호원이라는 가설을 사실로 적지 말 것.

## 3. 제조사 기준 MAX3295 핀맵과 극성

공식 MAX3293–MAX3295 데이터시트 기준 (SOT23-6):

| 물리 핀 | 이름 | 기능 | 신규 Rev.A 연결 |
|---:|---|---|---|
| 1 | DI | 로직 데이터 입력 | `SPDIF_CMOS` (TLV3601 OUT) |
| 2 | VCC | **3.3V ±5%** 전원 | `+3V3` |
| 3 | DE | HIGH일 때 드라이버 출력 활성화 | `+3V3` (OEM과 동일한 활성화 방향) |
| 4 | Z | 반전 차동 출력 | `DRV_Z` → R419에 대응 → **SPDIF−** |
| 5 | GND | 접지 | `GND` |
| 6 | Y | 비반전 차동 출력 | `DRV_Y` → R420에 대응 → **SPDIF+** |

출력 논리(`DE=HIGH`인 경우):

| DI | Y | Z | `Y − Z` |
|---|---|---|---|
| HIGH | HIGH | LOW | 양(+) |
| LOW | LOW | HIGH | 음(−) |

**결론:** 수정된 순정 KiCad 회로에서 `Y→SPDIF+`, `Z→SPDIF−`이므로 **MAX3295 논리 극성의 일반적 정의와 일치한다.**

- `DE`와 `VCC`를 묶어 항상 ON으로 구동하는 것은 순정 AVN 구조와 일치한다.
- U3 전원 바로 옆 `100nF` 디커플링 **필수**, 추가 `1µF` 검토. GND 리턴을 짧게.
- IC가 3.3V 공급이라고 차동 출력 한 선에서 **−3.3V가 직접 나오는 것이 아님**. 두 핀 각각은 GND 기준 양전압으로 동작하고, `Y−Z`가 양/음 전압을 나타낸다.
- MAX3295는 **20Mbps급**. 192kHz S/PDIF BMC 최대 전이 속도는 설계 여유가 불확실하므로 **우선 44.1/48kHz에서 테스트**, 고샘플레이트 호환성은 검증 전 미보장.

공식 문서: https://www.analog.com/media/en/technical-documentation/data-sheets/max3293-max3295.pdf

## 4. 신규 Rev.A 출력부 — 순정값 사용 + 극성 선택 옵션

### 4.1 기준 구조

```text
MAX3295 Y(6) ── C593 접속 노드 ── R_OUT_Y (120Ω) ── [극성 선택 Matrix] ──┐
                                                                           ├── F400 대체 CMC ── SPDIF+
MAX3295 Z(4) ── C593 접속 노드 ── R_OUT_Z (120Ω) ── [극성 선택 Matrix] ──┘                SPDIF−

출력측: R423 56Ω across SPDIF±
       C433 DNP across SPDIF±
       C430 DNP SPDIF+→GND, C431 DNP SPDIF−→GND
```

- OEM 대응: `R_OUT_Y = 120Ω (R420 대응)`, `R_OUT_Z = 120Ω (R419 대응)`, `R_DIFF = 56Ω (R423 대응)`.
- `C593`는 U3 Y/Z 사이, **직렬 120Ω 저항 이전**, 0805 C0G/NP0 풋프린트, **DNP**.
- `R_DIFF 56Ω`을 출력단에 둔 것은 OEM 복원 회로에 근거. 다만 **AMP 내부 종단 및 드라이버 출력 전압 마진**을 확인하기 전까지 진폭 보장은 불가. Rev.A에서는 56Ω 교체/미실장 가능한 풋프린트로 둔다.
- `F400`의 실제 제조사/주파수 특성은 미확정. 신규 후보 **TDK `ACM2012-900-2P-T002` (90Ω common-mode impedance @100MHz)**. 이 숫자는 직류저항 90Ω가 아님.
- `FL1` CMC를 실험상 우회할 수 있도록 선택적 0Ω 우회 풋프린트도 고려하되, **CMC와 우회 경로를 동시에 실장하지 않는 설계**를 명확히 표시.
- 출력 EMI용 `C430/C431/C433`는 처음에는 모두 **DNP**; 변경 가능한 C0G/NP0 0603/0805 풋프린트 권장.

### 4.2 극성 변경용 0Ω 저항 점퍼 매트릭스 (**옵션**)

목적: 원칙적으로 순정 극성을 사용하되 AMP 실제 입출력 명명 방식 차이·배선 실수·시험 편의를 위해 **PCB 수정 없이 두 차동선을 맞바꿀 수 있도록** 한다.

**배치:** 두 120Ω 직렬저항 **뒤**, 공통모드 초크 **앞**에 연결 선택 네트워크를 둔다. 그 이후 필터/커넥터는 항상 `PAIR_P / PAIR_N`으로 정리한다.

```text
DRV_Y ── R_OUT_Y(120Ω) ── NET_Y_AFTER_R ──┬── JP_Y_P(0Ω) ── PAIR_P → FL1 윗권선 → SPDIF+
                                            └── JP_Y_N(0Ω) ── PAIR_N → FL1 아랫권선 → SPDIF−

DRV_Z ── R_OUT_Z(120Ω) ── NET_Z_AFTER_R ──┬── JP_Z_N(0Ω) ── PAIR_N → FL1 아랫권선 → SPDIF−
                                            └── JP_Z_P(0Ω) ── PAIR_P → FL1 윗권선 → SPDIF+
```

| 설정 | **실장할 점퍼 두 개** | **반드시 DNP인 두 개** | 결과 |
|---|---|---|---|
| **기본/순정극성** | `JP_Y_P` + `JP_Z_N` | `JP_Y_N` + `JP_Z_P` | **Y→SPDIF+ / Z→SPDIF−** |
| 시험용/교환극성 | `JP_Y_N` + `JP_Z_P` | `JP_Y_P` + `JP_Z_N` | **Y→SPDIF− / Z→SPDIF+** |

**필수 안전 규칙**

- **동시에 4개를 실장하지 말 것.** 0Ω 링크의 다중 장착은 Y/Z 출력끼리 단락시킬 수 있다.
- BOM에는 0Ω 저항 **2개 실장, 2개 DNP**로 기재하고, 어셈블리 도면·실크에 기본 선택을 표시할 것.
- 케이스 내외부에 극성 선택 설정을 기록한다. **장착/탈거 및 변경은 ACC OFF 후** 수행한다.
- **ERC/DRC 통과만으로 점퍼 실장 조합의 안전성이 보장되는 것은 아니다.** 조립 후 Fluke로 `Y ↔ +`, `Z ↔ −`, `Y ↔ Z 단락 여부`를 확인하고, 운전용 출력 소자 보호 특성에 맞춰 판정해야 한다.
- 기판은 2-layer이며, 교차 라우팅 구간은 비아 등으로 처리하되 **Bottom GND plane 절단을 최소화**할 것.
- 점퍼 옵션이 공간/노이즈/조립 혼동을 지나치게 늘리면 Rev.A에서는 **기본 고정극성만 사용**해도 된다. 옵션은 필수 기능이 아니라 시험 편의 기능이다.

### 4.3 차동 출력 전압의 대략적인 감쇠

- 단순 이상적 가정(드라이버 이상적인 3.3V 차동 레벨, **AMP 측 추가 종단이 없고**, R=120Ω×2, 병렬 56Ω):

  `|Vdiff_out| ≈ 3.3 × 56 / (120 + 120 + 56) ≈ 0.624V`.

- **실제 전압 예측치가 아니다.** MAX3295의 실제 VOD/출력 저항, AMP 내부 종단, CMC·필터가 영향을 준다.
- 극성만 맞바꾸면 `Vdiff` 부호가 바뀌며 전기적 파손이 발생할 개연성은 낮지만, **ACC 12V를 신호선에 잘못 연결하는 등 배선 오류는 앰프 손상 위험이 있다.**

## 5. 신규 입력부 — DUDU7 75Ω 동축에서 MAX3295 DI까지

### 5.1 RCA→BNC 케이블

- DUDU7 RCA Female에 **RCA Male**, 보드 케이스에 **75Ω BNC Female**, 5m 동축 케이블 끝에 **BNC Male**.
- 연장거리는 Head Unit → 차량 내장재 우회 → 운전석 아래 AMP 근처. **5m 우선**.
- 가능한 유연한 75Ω 케이블(예: Canare L-3C2VS 등 3C급) 우선. 굵은 5C 케이블을 쓰면 **케이스/BNC에 가해지는 장력**을 고려.
- 패널 고정 BNC Female을 사용하고 PCB까지 짧은 75Ω 동축 피그테일로 연결. 커넥터 50Ω/75Ω 혼용 주의.

### 5.2 초기 비교기 설계(미검증)

```text
BNC center ──┬── R1 75Ω ── GND
             │
             └── C1 10nF (직렬 AC Coupling) ──●── TLV3601-Q1 IN+(3)
                                             │
+3V3 ── R2 10k ──────────────────────────────┤
                                             │
GND  ── R3 10k ──────────────────────────────┘

+3V3 ── R4 10k ──●── R5 10k ── GND
                 ├── C2 100nF ── GND
                 └── TLV3601-Q1 IN−(4)  [약 1.65V 기준]

TLV3601 OUT(1) ── SPDIF_CMOS ── MAX3295 DI(1)
```

TLV3601-Q1 SOT-23(DBV) 핀: **1 OUT / 2 VEE(GND) / 3 IN+ / 4 IN− / 5 VCC(+3V3)**. 공식 데이터시트 재확인.

- `75Ω`은 입력 PCB 지점에서 BNC center ↔ shield/GND로 종단한다. RCA S/PDIF은 **75Ω 종단에서 대략 0.5Vpp 규격을 가정**했으나 DUDU7 실물 전압 **미측정**.
- 비교기는 실제 전송 데이터의 전이를 복원하지만 **오디오 데이터를 디코딩하지 않는다**.
- 바이어스망 R2~R5와 기준 필터 C2는 **예비 토폴로지**. 기준 전압 변화, 내부 히스테리시스, 노이즈 유입, LV 출력 지터/가짜 전이 및 온도 변화 검증이 필요.
- TLV3601의 **입력 common-mode 범위, VIN absolute maximum, 출력 3.3V 호환성** 확인.
- U2 공급 바로 옆 `100nF` 디커플링(선택 `1µF` 추가) **필수**.
- **5m 케이블에 디지털 신호를 멀티미터만 연결해서는 Vpp/신호 품질을 확정할 수 없다**. Fluke 101은 R·V·DC·도통 점검용이며 정밀 시간영역 계측기가 아니다.

### 5.3 샘플링레이트 주의

- 우선 **44.1 / 48kHz** 오디오에서 검증.
- 96kHz 및 192kHz 지원은 **MAX3295 20Mbps 데이터레이트 한계 및 신호 지터**를 고려해 별도 확인. 192kHz S/PDIF BMC의 최단 전이 간격은 대략 40.7ns(최대 전이빈도 24.576MHz급)여서 보장을 내릴 수 없다.

## 6. 전원 — IBS 조건과 5V Buck 발열 저감

### 6.1 차량 제공 정보와 설계 제약

- i40 순정 AMP에는 **상시전원 3가닥**, **ACC/ON 1가닥**, GND가 존재한다는 사용자 제공 차량 회로도로 확인.
- 사용자가 측정한 차량의 일반적인 배터리·충전 전압: **시동 OFF 약 11.8~12.4V / 엔진 ON 약 13.4~14.4V**. 이는 **ACC OFF 해당 분기 핀의 실측 0V를 뜻하지 않는다.** 최종 하네스 확인 시 ACC/ON 선이 OFF에서 정말 차단되는지 확인.
- 사용자 조건: **IBS 배터리 센서 학습/초기화를 방해하는 비순정 상시부하 금지**. 따라서 신규 변환기에는 **상시 B+를 연결하지 않는다**.
- ACC OFF 시 **LDO까지 전원선에서 끊어지고**, BNC/AMP 신호선을 통한 역급전이 없도록 확인한다.

### 6.2 권장 전원 토폴로지

```text
J2-1 ACC_12V
      │
     F1    국부 퓨즈(0.5A 예비)
      │
     D1    직렬 역극성 보호(1N4007 임시 후보)
      │
      ├── D2 TVS 1.5KE27A → GND (Cathode = 보호된 VIN)
      ├── C3 벌크 10µF / 50V → GND
      ▼
U4: TI LMR16006YQ5DDCRQ1 (5V 고정, 2.1MHz 자동차용 Buck)
      │  [Buck 필수외장소자: 6.8µH 인덕터, Schottky, bootstrap 100nF,
      │   입력·출력 MLCC 등 — 반드시 데이터시트 기반 회로 구현]
      ▼
+5V_BUCK ── TP5V ── U1 TPS7B8333QDCYRQ1 (3.3V LDO)
                                    │
                                    ▼
                                  +3V3 ── U2 TLV3601-Q1
                                         └─ U3 MAX3295
J2-2 GND ───────────────────────── PCB GND plane
```

선형 LDO 방열 1차 근사 (`14.4V`, `40mA` 기준):

- **직결 LDO:** `(14.4−3.3) × 0.04 ≈ 0.444W`.
- **5V Buck 뒤 LDO:** `(5−3.3) × 0.04 ≈ 0.068W`.
- 이는 **LDO 발열만 약 85% 감소**한 비교. Buck 자체 손실이 존재하며 시스템 전체 효율 향상을 같은 비율로 표시해서는 안 된다.

### 6.3 후보 소자와 검증할 포인트

| 부품 | 후보 | 주의 |
|---|---|---|
| U4 | `LMR16006YQ5DDCRQ1`, 5V 고정 Buck | VIN 권장범위·SW 루프·2.1MHz EMI·자동차 과도전압 확인 |
| U1 | `TPS7B8333QDCYRQ1`, 3.3V LDO, SOT223 | 입력 5V, 출력 3.3V, 출력용량·TAB(GND)·열 설계 확인 |
| D1 | `1N4007-TP` | 전압강하, 역극성 보호 구성 및 작동온도 검증 |
| D2 | `1.5KE27A` | TVS 순간 클램프가 모든 load-dump 조건을 보장하지 않음 |
| L1 | `6.8µH` 시작값 | 포화전류, DCR, 제조사 권장 인덕터 재선정 |
| D3 | Buck 프리휠 Schottky | **Anode GND / Cathode SW** 확인 |
| Cboot | `100nF` 후보 | U4 `CB ↔ SW` 사이 |
| Cin(Buck) | `2.2µF` + 입력 벌크 후보 | 세라믹 DC bias/정격/리플 검증 |
| Cout(Buck) | `10µF` 후보 | 실효 용량 확인 |
| LDO Cin | `1~2.2µF` 후보 | 제조사 요구 출력 안정성 충족 |
| LDO Cout | `>=2.2µF` 후보 | 데이터시트 요구조건 검증 |
| F1 | `0.5A` 후보 | AMP 25A 분기라인이 얇은 추가 배선을 충분히 보호하지 않을 수 있음 |

**U4 핀(공식 TI LMR16006Y-Q1 데이터시트):** `1 CB`, `2 GND`, `3 FB`, `4 SHDN`, `5 VIN`, `6 SW`. **고정 5V형의 FB 연결은 제조사 애플리케이션 도면을 확인한 후 결정.** 구버전 SVG 또는 사용자 기억만으로 Buck 외장부품을 누락하지 말 것.

**U1 핀 (SOT-223):** `1 IN`, `2 GND`, `3 OUT`, `4 TAB/GND`. 최종 발주 후보의 패키지별 핀 기능·풋프린트를 검증한다.

**자동차 과도전압:** 입력 TVS·퓨즈·역극성 다이오드만으로 ISO 7637 / ISO 16750 / load dump 등을 충족한다고 단정할 수 없다. ACC 노드와 실제 차량 전원 경로의 최대 서지 및 부품 정격을 검증해야 한다.

## 7. 알루미늄 케이스와 PCB 레이아웃 조건

| 항목 | 계획 |
|---|---|
| 외함 | 소형 검정 **알루미늄 기성 케이스**, 우선 후보 **Hammond `1455C1201BK`** |
| 장착 | 차량 **순정 AMP 상단**에 보유 중인 **3M 차량용 내열 양면테이프**로 고정 |
| PCB | **2층 FR4, 모든 부품 Top**, Bottom은 연속적 GND Plane 위주 |
| BNC | 75Ω **패널 고정형 Female**, 내부 짧은 피그테일 또는 맞춤 연결 |
| 전원 | 2핀 탈착 커넥터 `ACC 12V / GND` |
| AMP 출력 | 3핀 탈착 커넥터 `SPDIF+ / SPDIF− / SPDIF GND` (케이스 엔드패널 가공/하네스 처리) |
| 발열 | Buck 채택, LDO GND 탭 구리면적·Thermal Via. 케이스 내부 열전달은 별도 검증 |
| 스트레인 릴리프 | 5m 동축 케이블과 AMP 하네스의 장력을 **케이스/차체에 분산** |
| 안전 | 알루미늄 케이스/PCB Bottom 구리/핀·실드가 의도치 않게 단락되지 않도록 절연 설계 |

- 케이스 후보 **외형 120×54×23mm 수준**. 이는 **PCB 허용 외형이 아니다.** 반드시 Hammond 상세 도면, PCB 삽입 홈 간격, 패널 내부, 커넥터 높이를 검증.
- **Buck 핫 루프**(스위치/Schottky/입력 MLCC)를 가장 짧게, `SW` 구리 면적 최소화. 민감한 BNC 입력과 1.65V 기준망에서 떨어뜨려 배치.
- 비교기 75Ω 종단 → AC 결합 → 입력 저항망 경로는 짧게. 신호 GND 리턴 확보.
- MAX3295→120Ω 2개→극성 점퍼→CMC→출력까지 차동 라우팅을 짧고 대칭적으로.
- **공통 GND plane을 불필요하게 분할하지 말 것.** BNC 쉴드, PCB GND, AMP SPDIF GND, 알루미늄 케이스, 차량 차체 GND 연결 정책은 회로·EMI 검토 후 확정.
- 케이스는 자체적으로 방열판이 되지 않음. LDO와 케이스 사이 실질적인 열전달 경로·절연 패드·주변 AMP 온도 확인 필요.
- PCB에 맞춰 엔드패널 가공을 해야 하며, 사용자는 기구 가공 능력이 제한적이므로 **케이스 먼저 선정 → 가공 방법 검토 → PCB 위치 확정** 순서 권장.

## 10. 제작·시험 게이트 및 계측 한계

### 10.1 KiCad 검토 순서

1. 제조사 데이터시트로 **MAX3295, TLV3601-Q1, 5V Buck, LDO** 전원·핀 번호·정격 확인.
2. **KiCad 실제 `.kicad_sch` 작성**. 가장 먼저 OEM 복원 출력단을 그림과 동일하게 구성하고, 출력 기본 극성 검토.
3. 입력 Comparator의 DC bias, 75Ω 로딩, BMC 신호 정형 안정성과 온도·전원변동 검토.
4. `5V Buck`의 **모든 필수 외장소자 및 PCB 레이아웃 제약** 확정.
5. 0Ω 극성 매트릭스의 **기본 2개 실장 조합 / 절대 동시실장 금지 사항**을 실크 및 조립도에 표기.
6. KiCad ERC → netlist/핀맵 검증 → BOM/풋프린트 확정 → **사용자 SCH 리뷰**.
7. 케이스 내부 치수 확인 → 2층 Top 실장 PCB → DRC → 3D 충돌검사 → 제조용 Gerber 및 Drill 생성.
8. **발주 전 반드시 사용자 최종 승인.**

### 10.2 실물 테스트

| 단계 | 장비 | 확인 사항 |
|---|---|---|
| PCB 미통전 | **Fluke 101** | +3.3V-GND 단락 없음; 전원선 및 0Ω 점퍼 조합; OEM 복원 부품값; 신호·전원 오접속 없음 |
| 전원만 | 전류제한 DC 벤치전원 + Fluke | `5V`, `3.3V`, 전원 소비전류, 전원 IC 과열 여부 |
| Buck 리플/스타트업 | 오실로스코프 권장 | 5V 리플, 3.3V 품질, 로직 전원 순서 |
| 신호 입력 | 오실로스코프 필요 | 실제 DUDU7 75Ω 종단 후 Vpp, 신호 에지, 입력 반사/잡음 |
| Comparator | 오실로스코프 필요 | VREF, OUT 로직 BMC, 지터/오검출/고정 HIGH/LOW 여부 |
| MAX3295 | 오실로스코프 필요 | Y/Z 극성, 최종 차동 전압, 56Ω과 AMP 병렬 부하 상태 |
| EMI | 실차 기능시험 + 필요시 계측 | 출력 필터 DNP vs populated, 주변 수신 간섭, 오디오 끊김 |
| 차량 OFF | 전원/암전류 확인 | ACC 실제 0V, BNC/AMP로부터 역급전 없음, IBS 휴지 상태 방해 없음 |
| 열/진동 | 장시간 주행/고온시험 | 전원 IC/AMP 케이스 온도, 동축 케이블 장력, 양면테이프 박리 |

- 현재 사용자의 멀티미터는 **Fluke 101**. **10~100pF급 MLCC 측정, S/PDIF 타이밍 파형, 고속 차동 신호 품질 확인 용도로는 부족**하다.
- Raspberry Pi Pico 2 로직애널라이저는 구입을 고려했던 장비일 뿐이며, **미구입 상태**. 아날로그 RCA 입력(0.5Vpp 가정)을 3.3V GPIO에 직결 금지.
- 앰프를 연결하기 전, 충분한 전원/출력 확인과 배선 검증을 선행한다. 특히 **ACC 12V가 AMP의 SPDIF 신호선에 들어가는 오류를 절대 피할 것**.

## 13. 로컬 에이전트에게 전달할 최종 작업 지시

> 본 문서 `Rev.A2`를 최우선으로 읽고, **순정 AVN의 최종 수정 KiCad 캡처**를 기준으로 MAX3295 출력 극성과 실측 저항을 반영하라.  
> **Y(6)→R420 120Ω→F400→SPDIF+**, **Z(4)→R419 120Ω→F400→SPDIF−**. 순정에서 **DE(3)는 VCC(2)에 연결**된다.  
> 신규 회로는 **75Ω BNC 입력 → TLV3601-Q1 → MAX3295 → OEM 복원 출력 네트워크**와 **ACC 12V→5V Buck→3.3V LDO**로 구성하라.  
> **기본 극성 두 점퍼만 실장하는 선택형 0Ω 저항 교환 매트릭스**를 고려하고, 잘못된 점퍼 조합에서 차동 출력을 단락시키지 않도록 조립상 금지 사항을 적어라.  
> 4개 EMI 커패시터는 풋프린트만 만들고 **초기 DNP**; U2/U3 및 전원 IC의 **디커플링은 반드시 실장**하라.  
> 신호 수신 진폭, 비교기 바이어스, AMP 종단, Buck EMI/서지 보호, 실제 열 설계는 미검증이므로 데이터시트 검토·시뮬레이션·벤치 검증 항목으로 관리하라.  
> **우선 `.kicad_sch`/ERC와 검증 보고서를 작성하고 사용자 확인을 받은 후 PCB/Gerber로 진행**하라. 모든 부품은 PCB Top에만 배치하고 Hammond 후보 케이스의 실제 내측 규격을 먼저 확인하라.
