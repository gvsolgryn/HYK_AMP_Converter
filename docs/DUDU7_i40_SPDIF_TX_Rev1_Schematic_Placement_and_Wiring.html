이 문서는 Rev.1 logical reference에 실제 KiCad 참조 번호를 배정한 작업 가이드입니다. 선정 MPN과 FIT/DNP를 임의로 바꾸지 않습니다. 커넥터와 CMC의 물리 패드 번호는 실제 부품 도면으로 확인하기 전까지 확정하지 않습니다.

1. 배치할 심볼 체크리스트

각 부품을 KiCad에 배치하고 값·실장 상태를 확인한 뒤 체크하세요. 체크하면 행이 흐려지고 상단 진행률에 반영됩니다.

1.0 KiCad 공용 심볼 사용 방법

정확한 제조사 심볼이 없어도 회로도는 그릴 수 있습니다. 심볼 모양·핀 번호, Value의 실제 MPN, Footprint의 실제 패키지를 따로 선택하면 됩니다. 공용 심볼을 사용했다는 이유로 Value를 Diode, 1.5KExxCA, Conn_01x03 같은 일반 이름으로 두면 안 됩니다.

대상사용할 심볼사용 방법
U1Converter_DCDC:TSR_1-2450KiCad 공용 정확형 심볼이 있으므로 그대로 사용 가능. 1=VIN, 2=GND, 3=VOUT 확인 완료. 현재 공용 심볼과 기본 TSR-1 풋프린트 조합 사용 가능.
U2symbols:TPS7B8350QDCYRQ1핀맵 재사용 가능. Value는 반드시 TPS7B8333QDCYRQ1로 변경. Footprint는 UL_FP_TPS7B83:SOT_8350QDCYRQ1_TEX-L.
U3symbols:TLV3601QDBVRQ1검증된 프로젝트 심볼 사용. 1=OUT, 2=GND, 3=IN+, 4=IN−, 5=VCC.
U4symbols:MAX3295AUT_V+T동일 핀맵 재사용 가능. Rev.1 Value는 반드시 MAX3295AUT+T로 변경. Y=6, Z=4.
D1Device:D_Schottky공용 Schottky 심볼 사용 가능. 1=A, 2=K, Value SB360, Footprint SB360:P2_DO-201.
D2Diode:1.5KExxCA 또는 Device:D_TVS둘 다 양방향 TVS에 사용 가능. Value는 정확히 1.5KE22CA로 변경. 현재 Diode_THT:D_DO-201AE_P15.24mm_Horizontal 사용 가능.
F1 / FH1symbols:3557-2 또는 Device:Fuse홀더 심볼 핀 1_1/1_2, 2_1/2_2와 새 풋프린트 패드는 일치. Value/MPN은 실제 퓨즈 0891002.NXS, 별도 속성 HOLDER_MPN=3557-2, Footprint FUSE_3557-2:FUSE_3557-2로 지정.
L1Device:Filter_EMI_LL_1423공용 2라인 필터 후보. 실제 CMC와 풋프린트의 채널이 1→4, 2→3일 때만 사용. Value ACM2012-900-2P-T001. 채널이 다륩면 전용 심볼 사용.
J1Connector:Conn_Coaxial공용 동축 심볼 사용 가능. Value KH-BNC75-3511. CENTER/SHIELD와 실제 BNC 풋프린트 패드 매핑은 별도 확인.
J2Connector_Generic:Conn_01x03공용 3핀 심볼 사용 가능. Value는 실제 구매한 XH 커넥터 MPN으로 변경하고 pitch·핀 순서 확인.
J3Connector_Generic:Conn_01x02공용 2핀 심볼 사용 가능. Value JST B2PS-VH. ACC/GND의 실제 패드 번호 확인.
C1Device:C_Polarized극성 전해커패시터 심볼. Value 22uF/50V, 실제 MPN·직경·리드 간격은 구매 부품으로 확정.
C2~C14Device:C일반 커패시터 심볼. 각 행의 값과 FIT/DNP를 그대로 적용하고 0805 풋프린트 지정.
R1~R16Device:R일반 저항 심볼. 각 행의 값·FIT/DNP 적용. 0805 풋프린트 지정.
TP1~TP13Connector:TestPoint공용 테스트포인트 심볼. 각 행의 Net 이름으로 연결.
전원power:+5V, power:+3V3, power:GND공용 전원 심볼 사용. PWR_FLAG는 ERC에서 전원 공급 오류가 발생하는 위치에만 추가.
새로 받은 프로젝트 심볼도 그대로 사용할 수 있습니다. TSR과 3557-2 심볼의 기본 Footprint 필드는 프로젝트 닉네임인 CONV_TSR_1-2450, FUSE_3557-2에 맞췄습니다. U1은 공용 정확형 심볼이 이미 있으므로 굳이 프로젝트 심볼로 교체할 필요는 없습니다.
