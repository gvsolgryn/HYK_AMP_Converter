### 3.3 PCB 설계 제약 (외함에서 나온 것)

- **길이 100 mm (본체 107 mm보다 7 mm 짧음)**: PCB **앞 가장자리를 본체 앞끝에 맞추고**(J1 나사부가 앞판 관통, 결정 #17), 뒤쪽 약 7 mm는 뒷판까지 빈 공간으로 둔다. PCB는 홈과 J1 판넬 너트로 위치가 정해지므로 뒤가 떠 있어도 된다. 이 공간은 J2·J3 플러그·전선용으로 쓴다.
- **아래면**: Bottom에 부품 없음(전 부품 Top 규칙 유지). THT 리드는 **1.5 mm 이하로 자르면 모든 위치에서 안전** (긴 변 3.9 mm 이내는 위 표 제약).
- **긴 변**: 부품 코트야드는 긴 변에서 **2.0 mm 이상**, 높이 15.2 mm 초과 부품(현재 없음)은 3.9 mm 이상 떨어뜨린다. 현재 가장 높은 부품: J1 12.5, F1+퓨즈 ≈ 13, C1 11 mm.
- **높이 예산 19.4 mm**: BNC, 퓨즈홀더+퓨즈, TSR 모듈, VH 커넥터, C1 전해(세워서 6.3×11 가정)의 실제 높이를 각 데이터시트로 확인하고 3D(STEP)로 간섭 검사.
- 3D 확인: `Case_RT75:CASE_RT7511` 풋프린트를 배치하고 3D 뷰어(Alt+3)에서 본다. 뚜껑이 닫힌 모델이라 안쪽은 반투명 설정이나 단면으로 확인.
- **J1 앞판 구멍**: 중심 = 외부 바닥에서 **19.65 mm**(PCB 윗면 8.65 + BNC 축 11.0), 가로는 J1 위치(기판 긴 변에서 20 mm → 판넬 세로 중심선에서 14.75 mm). 판넬 나사 구멍(67.2 × 22.8)과 간섭 없음.

## 4. J1 BNC — Kinghelm KH-BNC75-3511

`references/datasheets/KH-BNC75-3511.pdf` (도면 해상도가 낮아 □ 표시 값은 풋프린트 제작 때 재확인).

| 정격 | 75 Ω, DC~3 GHz, VSWR ≤ 1.3 |

### 4.1 장착 방식 (결정 #17)

- J1을 PCB **앞 가장자리**에 두고, 나사부가 PCB 앞 가장자리 밖으로 나와 **앞판(1.5 mm)을 관통**한 뒤 바깥에서 와셔·너트로 고정.
- 케이블 장력은 판넬 너트가 받고, PCB 납땜부에는 거의 가지 않는다. 피그테일 없음.
- 판넬 구멍 중심 높이(외부 바닥 기준) ≈ PCB 윗면 8.8 + 축 높이 약 11 ≈ **19.8 mm** □. 판넬 높이 30.9 안에 들어가고, 판넬 나사 구멍(67.2 × 22.8)과는 J1을 가로 중앙 근처에 두면 겹치지 않는다.
- 조립 순서: 앞판을 BNC 나사부에 끼우고 너트 고정 → PCB와 앞판을 함께 본체 홈에 밀어 넣기 → 앞판 볼트 → 뒷판 볼트.
- D형 직선부 방향을 PCB 기준으로 정해 판넬 가공 도면에 표시.

### 4.2 접지 정책 (미결)

- 나사부가 판넬에 닿으면 BNC 쉴드(=PCB GND)와 케이스가 연결된다. **아노다이징 피막은 절연**이라 그대로 두면 접촉이 불안정하다.
- 권장안(사용자 미확정): 구멍 주변 피막을 벗기고 톱니 와셔로 **케이스를 GND에 확실히 연결**, 대신 **케이스는 차체에 닿지 않게**(벨크로·절연 브래킷) 고정해 GND가 J3 한 곳으로만 차체에 연결되게 한다.
- 회로도 옵션 미결: J1 쉴드↔GND 사이 0Ω 패드를 둘지.

## 5. PCB에서 할 일 (순서)

1. **기판 설정**: 2층, 1.6 mm, Edge.Cuts **69.5 × 100.0 mm** (결정 #18). User 레이어에 앞·뒤 판넬 위치(앞판 = PCB 앞 가장자리, 뒷판 = 뒤 가장자리 + 7 mm)와 긴 변 보스 금지 구역(§3.3) 표시.
2. **J1 전용 풋프린트 제작** (§4 치수, 데이터시트 원문 대조). 심볼 핀 1/2와 패드 번호 일치 확인. 앞 가장자리 기준으로 나사부 돌출량 = 판넬 1.5 + 와셔 + 너트 + 여유.
3. **미확정 풋프린트 정리**
   - C1: 0805 임시 → 실물 전해(예: 22 µF/50 V, D6.3 × 11, P2.5 → `CP_Radial_D6.3mm_P2.50mm` 후보, 구매품 확정 후 결정)
   - J2: 정품 JST `S3B-XH-A`(2.50 mm) 유지 여부 = 구매품 확정 필요
4. **Update PCB from Schematic** 후 배치. 배치 원칙은 §8.1:
   - J1 → R1(75Ω) → C9 → U3 입력 경로 최단, VREF 분압(R3·R4·C10)은 U3 옆
   - U4 → R7/R8 → 극성 매트릭스 → FL1 → R9 → J2 차동 경로 짧고 대칭
   - C7·C8 디커플링은 각 IC 전원 핀 바로 옆, C1·C4·C5·C6은 TSR/LDO 옆
   - TSR 1 모듈 아래 배선 금지(데이터시트 "Avoid routing PCB traces under the converter")
   - Bottom은 연속 GND plane, 전 부품 Top
   - J2·J3은 케이스 **안쪽** PCB 위, 하네스는 뒷판 그로밋(권장안) 쪽으로
5. **실크**: J2·J3 패드 옆 `ACC` `GND` / `SP+` `SP−` `GND`, 극성 매트릭스 주의 문구, DNP 표시.
6. **3D 간섭 확인**: RT-7511 STEP과 함께 높이·보스·판넬 확인.
7. **DRC** → 사용자 검토. **Gerber 생성·부품 주문은 사용자 승인 전 금지** (AGENTS 작업 규칙 3).
8. PCB 확정·시제품 맞춤 확인 **후** 판넬 가공(앞판 BNC D형 구멍, 뒷판 그로밋), 레이저 마킹, 실크 인쇄(케이스포유 의뢰 가능).

## 8. 이전 문서에서 가져온 유효 내용

옛 문서(`docs/archive/`)는 기본적으로 읽지 않는다. 아래는 그중 Rev.1에도 여전히 유효한 내용만 옮긴 것이다. 출처 표기는 `archive/…RevA2…` 기준.

### 8.1 PCB 배치·배선 원칙 (Rev.A2 §7을 Rev.1에 맞게 수정)

- 2층 FR4, **전 부품 Top**, Bottom은 연속 GND plane. **GND plane을 불필요하게 분할하지 않는다.**
- 스위칭 전원(TSR 1 모듈)과 C1·C2 입력 루프는 짧게. 민감한 **BNC 입력과 1.65V VREF 망에서 멀리** 배치.
- 75Ω 종단(R1) → AC 결합(C9) → 바이어스(R2) → U3 경로는 짧게, 신호 GND 리턴 확보.
- MAX3295 → 120Ω × 2 → 극성 매트릭스 → CMC → 출력 차동 경로는 **짧고 대칭**.
- 케이스는 스스로 방열판이 아님. LDO(U2) GND 탭에 구리 면적·thermal via.
- 케이스·PCB Bottom 구리·핀·실드가 의도치 않게 단락되지 않도록 절연 고려(§3.3 아래 4.5 mm).
- 5 m 동축과 AMP 하네스의 장력은 케이스/차체로 분산(BNC는 판넬 너트, 하네스는 그로밋·케이블타이).
- 극성 매트릭스의 **기본 2개 실장 / 4개 동시 실장 금지**를 실크·조립도에 표기.

### 8.2 제작·시험 게이트 (Rev.A2 §10)

KiCad 쪽 순서: 데이터시트 핀·정격 확인 → 회로도 → ERC → 넷리스트/핀맵 검증 → BOM/풋프린트 확정 → **사용자 회로도 리뷰** → 케이스 치수 → PCB → DRC → 3D 충돌 검사 → Gerber/Drill → **발주 전 사용자 최종 승인**.

| 단계 | 장비 | 확인 사항 |
|---|---|---|
| PCB 미통전 | Fluke 101 | +3.3V–GND, +5V–GND 단락 없음 · 0Ω 점퍼 조합 · 부품값 · 전원/신호 오접속 |
| 전원만 | 전류제한 DC 전원 + Fluke | +5V, +3.3V, 소비전류, 전원부 과열 |
| 전원 리플/기동 | 오실로스코프 권장 | +5V 리플(TSR 500 kHz), +3.3V 품질 |
| 신호 입력 | 오실로스코프 필요 | DUDU7 출력을 75Ω 종단한 상태의 Vpp, 에지, 반사·잡음 |
| 비교기 | 오실로스코프 필요 | VREF, CMP_OUT BMC 파형, 지터·오검출·고정 HIGH/LOW |
| MAX3295 출력 | 오실로스코프 필요 | Y/Z 극성, 최종 차동 전압(56Ω + AMP 병렬 부하) |
| EMI | 실차 기능시험 | 출력 EMI 커패시터 DNP vs 실장, 라디오(AM) 간섭, 음 끊김 |
| 차량 OFF | 전원·암전류 | ACC가 실제 0V, BNC/AMP 쪽 역급전 없음, IBS 휴지 상태 방해 없음 |
| 열/진동 | 장시간 주행·고온 | 전원부·케이스 온도, 동축 장력, 고정 상태 |

### 8.3 계측 한계와 안전 (Rev.A2 §10.2)

- 사용자 계측 장비는 **Fluke 101 멀티미터뿐**. 10~100 pF MLCC 측정, S/PDIF 파형, 차동 신호 품질 확인에는 부족 → 오실로스코프 확보 또는 외부 계측 필요.
- Raspberry Pi Pico 2 로직애널라이저는 **미구입**. 아날로그 동축 신호(약 0.5 Vpp)를 3.3V GPIO에 직결 금지.
- AMP 연결 전 전원·출력·배선 확인 선행. **ACC 12V가 AMP SPDIF 신호선에 들어가는 오배선 절대 금지.**

### 8.4 OEM 분석에서 남은 사실 (Rev.A2 §2)

- 순정 AVN 출력단 실측: Y/Z 직렬 120Ω(R419/R420), F400 4단자(2라인 CMC 추정, 경로 DC 약 1Ω), AMP 쪽 차동 56Ω(R423). Rev.1 출력 토폴로지가 이를 복제함.
- OEM C593/C433/C430/C431 값은 **미측정·복제 금지** → Rev.1 C11~C14 `TBD`, DNP.
- **SPDIF−는 GND가 아니다.** AMP 커넥터 핀 배열은 실차 배선으로 직접 확인.
- AMP 입력 임피던스·내부 종단·허용 레벨은 미확인 (§6 미결, 미완료 검증).
